# Experimental archive

This directory preserves the alternate formulations and conventional reference
behind the canonical implementation. These files are not supported APIs or
claims of a practical cryptanalytic technique.

- `relaxations/` contains documented probability-coercion, log-probability, and
  logit versions of the tensor logic.
- `reference/sha256_scratch.py` is a conventional integer SHA-256 reference
  retained for comparison and attribution.

The supported code lives in `../src/bbtsha/`.
